AI Together — MCP Server v2.0

Kết nối AI Assistant
vào hệ thống quản lý dự án

Hướng dẫn cài đặt MCP Server để Antigravity, Cursor, Claude Desktop hoặc bất kỳ AI assistant nào có hỗ trợ MCP kết nối vào AI Together.

1

Yêu cầu trước khi cài đặt

Node.js ≥ 20

Kiểm tra: node --version. Cài từ nodejs.org nếu chưa có.

Tài khoản AI Together

Bạn cần đã có tài khoản trên hệ thống. Liên hệ Chairman nếu chưa được cấp.

API Key

Vào Profile → API Key → Generate API Key trên giao diện web để lấy key.

2

Lấy API Key

Đăng nhập vào AI Together

Truy cập hệ thống web (VD: https://ai-together.your-domain.com).

Mở trang Profile

Click vào avatar góc trên bên phải → chọn Profile.

Tạo API Key

Tìm mục "API Key", bấm "Generate API Key". Sao chép key và lưu ở nơi an toàn.

Bảo mật: API Key cho phép truy cập đầy đủ vào tài khoản của bạn. Không chia sẻ công khai và không commit vào Git.
3

Cấu hình cho AI Assistant

Chọn AI assistant bạn đang sử dụng:

Mở file .gemini/settings.json tại thư mục project (hoặc home directory) và thêm:

.gemini/settings.json 
{
  "mcpServers": {
    "libe-aios": {
      "command": "npx",
      "args": ["tsx", "src/mcp/server.ts"],
      "cwd": "/đường-dẫn-tới/libe-aios",
      "env": {
        "LIBE_API_URL": "https://ai-together.your-domain.com",
        "LIBE_API_KEY": "your-api-key-here"
      }
    }
  }
}

Mở file .cursor/mcp.json tại thư mục project và thêm:

.cursor/mcp.json 
{

4

Biến môi trường

Biến Mô tả Ví dụ
LIBE_API_URL URL của hệ thống AI Together (bao gồm protocol, không có trailing slash) https://ai-together.libe.net
LIBE_API_KEY API Key cá nhân của bạn (lấy từ Profile) ak_xxxxxxxx...
KHÔNG commit API Key vào Git! Thêm file config MCP vào .gitignore nếu chứa key trực tiếp.

Kiểm tra kết nối

Sau khi cấu hình xong, mở AI assistant và thử hỏi:

Thử nghiệm 
# Hỏi AI assistant của bạn:
"Liệt kê tất cả các dự án trong hệ thống AI Together"

# Hoặc:
"Cho tôi xem các module được giao cho tôi"

# Hoặc:
"Tạo 1 task mới trong module MOD-001 với tiêu đề 'Fix login bug'"
Thành công! Nếu AI assistant trả về danh sách project hoặc module, MCP đã được kết nối đúng.

Nếu gặp lỗi, kiểm tra:

  • Đường dẫn cwd trỏ đúng đến thư mục libe-aios
  • LIBE_API_URL chính xác (bao gồm https://)
  • LIBE_API_KEY hợp lệ (chưa bị regenerate)
  • Node.js phiên bản ≥ 20 đã cài đặt
  • Server AI Together đang chạy và có thể truy cập
