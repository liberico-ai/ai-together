## Happy path
1. [ ] **Login** `dmstest` → vào app (không bị chặn bởi profile/bt.saleman).
2. [ ] Tab **"Hôm nay"** mở mặc định → đúng KH theo thứ trong tuần, sắp theo `sequence`, header `[Thứ X — tuyến — N KH]`, progress 0/N.
3. [ ] **Check-in** 1 KH (gần toạ độ) → toast thành công; thẻ chuyển xanh; progress tăng; lịch sử check-in trong CustomerDetail có dòng mới.
4. [ ] Check-in **"GĐ bưu điện xã"** (vnpost_xa) → ghi đúng loại (nguồn K5).
5. [ ] **Ngoài bán kính (>100m)** → dialog cảnh báo "vẫn check-in?".
6. [ ] **Tạo đơn** từ thẻ KH (hoặc CustomerDetail) → đơn tạo, liên kết KH.
7. [ ] **KH mới**: FAB → form → validate SĐT → lưu (online trả code) / "Lưu & Tạo đơn ngay".
8. [ ] **KPI** (tab Báo cáo): 5 card K1–K5 + tổng điểm + verdict (khi BE `kpi_report` sẵn sàng).
