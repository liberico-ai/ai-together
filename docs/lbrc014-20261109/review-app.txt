## 4. Trạng thái deviations — ĐÃ ĐÓNG (đợt FIX 04/06/2026)

> Theo **Quyết định Qa** + `11_FIX_PLAN_GATE30.md`. Cả 6 Lệch đã xử lý; không còn mục chờ Tech Lead phía App.

**✅ Lệch #1 — F9 visit_flow là lối vào DUY NHẤT (đóng `633fb15`).**
`VisitFlowScreen` được nối từ Route View (nút "Viếng thăm") và CustomerDetail (`CustomerVisitCard` → key `open_visit_flow`). Là lối vào check-in duy nhất tại điểm bán (QD-16).

**✅ Lệch #2 — Bỏ check-in nhanh không ảnh ở Route View (đóng `633fb15`).**
Gỡ `_quickCheckin` + Dismissible swipe-tự-check-in. Nút card đổi thành "Viếng thăm" mở visit_flow; "Đã thăm" khi `checkin_today`. Không còn check-in bỏ qua QD-09. Test `route_screen_test.dart` xác nhận không còn nút "Check-in" nhanh / `Dismissible`.

**✅ Lệch #3 — Check-in trong visit_flow: ảnh BẮT BUỘC + payload đủ field (đóng `633fb15`).**
`checkin_step.dart`: ảnh bắt buộc (chặn `_open` + `canOpen` yêu cầu `_photoPath`), camera-only, thêm chọn `checkin_type` (KH thường / GĐ bưu điện xã). `visit_service.openVisit` gửi `photo_taken_at` + `checkin_type`, context upload `note`→`checkin`. Test `visit_service_test.dart` (openVisit kèm ảnh).

**✅ Lệch #4 — Home "Đi tuyến hôm nay" → tab Hôm nay (đóng `f05dd83`).**
`home_screen.dart` card gọi `onNavigate(5)` (tab Hôm nay, pilot `bt.saleman/today_route`); gỡ push `TodayRouteScreen` legacy (`rt.mobile/today_route`). Giữ code `TodayRouteScreen`/`route_service` (không xoá).

**✅ Lệch #5 — Filter nhóm KH server-side (đóng `54f1413`).**
`customer_service.dart` nhận `domains`; `customer_list_screen` chip truyền `domains` (vd `[['nhom_member','=','N4']]`), refetch khi đổi filter, load-more bật cho mọi filter.

**✅ Lệch #6 — Cleartext debug-only (đóng `777a2d2`).**
Gỡ `usesCleartextTraffic` khỏi manifest main (release không cleartext); chuyển sang `android/app/src/debug/AndroidManifest.xml` qua `tools:replace`.

**✅ API `create_order` — BE đã bổ sung shape (REVIEW_BE §2.12 preview + §2.13 create_order).** App khớp về cấu trúc (xem §2). `client_uuid` (UUID v4) hợp lệ làm Idempotency-Key (`^[A-Za-z0-9_.:-]{8,128}$`).

**Còn phụ thuộc bên ngoài (không phải lỗi App):** Goong Maptiles key, target K1/K4/K5, chính sách quyền riêng tư tracking, nguồn `dms_visit_group` + mapping `employee_id↔user` — xem REVIEW_BE §4 Open items.

## 5. Checklist test thiết bị thật (QA)

- [ ] **Visit_flow là lối vào duy nhất:** từ Route View (nút "Viếng thăm") VÀ CustomerDetail (nút "Check-in / Viếng thăm") đều mở luồng 7 bước; KHÔNG còn check-in nhanh / swipe.
- [ ] **Bước check-in trong flow — ảnh BẮT BUỘC + camera-only:** nút "Mở viếng thăm" disabled tới khi chụp ảnh; KHÔNG có chọn ảnh từ thư viện; chọn được loại điểm (KH thường / GĐ bưu điện xã).
- [ ] **required_steps:** ép check-in + check-out; bước tuỳ chọn (kiểm tồn/trưng bày/ghi chú/đơn) bỏ qua được; chặn check-out khi thiếu bước bắt buộc.
- [ ] **Chống ảnh cũ (QD-09):** chụp ảnh trong flow, đợi >180s rồi check-in → BE từ chối (kiểm `photo_taken_at`).
- [ ] **vnpost_xa qua flow:** chọn "GĐ bưu điện xã" → BE bridge ghi `bt_saleman_checkin` đúng loại (K5 đếm).
- [ ] **GPS:** ngoài bán kính hiện ô nhập lý do; lấy vị trí; `LocationFailure` báo lỗi rõ.
- [ ] **Offline:** airplane mode → mở visit/đơn vào outbox; bật mạng → đẩy đúng thứ tự (upload ảnh `context=checkin` TRƯỚC visit.open), KHÔNG trùng (idempotent `client_uuid`).
- [ ] **Chấm công:** selfie camera bắt buộc; check-in mở ca → tracking nền bắt đầu (sau khi đồng ý); check-out → tracking dừng.
- [ ] **Tracking nền:** chỉ gửi `rt.track/push` khi đang ca; quyền vị trí "Always" được xin.
- [ ] **Bản đồ Goong:** khi BE trả key → render điểm theo sequence + màu đã/chưa thăm; tap → chỉ đường Google Maps; thiếu key → fallback danh sách.
- [ ] **Filter KH server-side:** chọn chip N3 GT/N4/Rượu → danh sách lọc đúng + cuộn load-more vẫn chạy.
- [ ] **Home "Đi tuyến hôm nay":** mở đúng tab Hôm nay (không mở màn legacy).
- [ ] **Release build (Android):** xác nhận release KHÔNG cleartext (chỉ debug http BE local).
- [ ] **KPI:** khi BE `kpi_report` sẵn sàng → 5 card đúng %, score, verdict badge.
- [ ] **E2E happy path:** login → tab Hôm nay → Viếng thăm (ảnh) → tạo đơn → check-out → KPI (iOS + Android).
